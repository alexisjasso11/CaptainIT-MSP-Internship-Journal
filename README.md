### What I Did
- **Firewall & VPN** — configured and deployed SonicWall TZ80 firewalls and a site-to-site IPsec VPN tunnel across two client locations, troubleshooting DHCP and DNS issues during live network cutover
- **Enterprise Server Administration** — rebuilt a Dell PowerEdge R640 from scratch (iDRAC reset, Windows Server 2025 install via Rufus, AD DS role setup) and repeated the process on a Dell OptiPlex 3080 for a live client domain migration, including virtual NIC configuration for inter-server communication
- **Driver Troubleshooting** — resolved an M.2 SSD not populating during Windows 11 install by identifying missing Dell storage controller drivers and injecting them manually mid-setup
- **Identity & Access Management** — audited MFA authentication methods across all managed client tenants in Microsoft Entra ID, flagging SMS-based auth users ahead of Microsoft's deprecation
- **Microsoft 365 Administration** — managed licensing, shared mailboxes, distribution lists, and email provisioning across multiple client tenants
- **Active Directory** — user onboarding/offboarding, permissions, shared drive mapping, and group policy in live client environments
- **Backup & Storage** — configured Synology NAS and Datto for automated backups across local, VDI, and M365 environments; resolved GEO IP block and DNS misconfiguration during setup
- **On-Site Support** — desktop migrations, printer troubleshooting, hardware replacements, network discovery, asset tagging, data extraction, and device wiping across client locations
