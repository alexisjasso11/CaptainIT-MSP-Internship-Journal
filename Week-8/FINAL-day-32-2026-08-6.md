## What I'm Leaving With

### Technical Skills Gained
- **Firewall & VPN** — configured a SonicWall TZ80 next-generation firewall in the office, deployed it on-site at a client location, and set up a site-to-site IPsec VPN tunnel between two physical locations. Troubleshot stale DHCP leases and DNS cache issues during the network cutover across multiple machines.
- **Enterprise Server Administration** — configured a Dell PowerEdge R640 from scratch: reset a locked iDRAC via BIOS factory reset, flashed Windows Server 2025 via Rufus bootable USB, set boot sequence, and installed AD DS roles following a SOP. Later repeated the full Windows Server configuration process on a Dell OptiPlex 3080 for a live client domain migration.
- **Windows Installation & Driver Troubleshooting** — diagnosed and resolved an M.2 SSD not populating during a Windows 11 clean install by identifying missing storage controller drivers, locating the correct Dell driver by service model, and injecting it manually during setup.
- **Identity & Access Management** — audited primary MFA authentication methods across all managed client tenants in Microsoft Entra ID, flagging users relying on SMS-based auth ahead of Microsoft's deprecation. Directly applicable to cloud security and IAM engineering.
- **Microsoft 365 Administration** — managed user licensing, shared mailboxes, distribution lists, email provisioning, and permissions across multiple client tenants through the M365 Admin Center.
- **Active Directory Administration** — created and managed user accounts, permissions, and group policies in live client environments. Onboarded and offboarded employees, mapped shared network drives via RDP.
- **NAS & Backup Administration** — configured Synology NAS for network drive mapping and automated backups across local, VDI, and Microsoft 365 environments. Deployed Datto backup agents on client endpoints. Diagnosed and resolved a GEO IP block and DNS misconfiguration during NAS setup.
- **Networking & Diagnostics** — used ipconfig /release, /renew, /flushdns across client environments. Conducted network discovery, asset tagging, and infrastructure mapping across multiple client sites.
- **On-Site Client Support** — desktop migrations, hardware replacements, printer troubleshooting (resolved a printer issue independently using HP Smart while the senior tech handled a second), data extraction, device wiping, and vendor escalation.

### Soft Skills & Professional Growth
- **Proactivity** — almost every on-site visit I joined, I asked to be part of. Waiting to be assigned things is how you stay on the sidelines. Asking is how you get experience.
- **Escalation judgment** — learned when to push through a problem independently and when to bring in a senior tech or vendor. Both matter equally.
- **Adaptability** — plans changed mid-project (R640 → OptiPlex 3080), hardware didn't cooperate (M.2 drivers, stale DHCP leases, GEO IP blocks), and client environments were always messier than expected. None of it stopped forward progress.

## The Unexpected Lesson
The most valuable thing I learned at Captain IT wasn't a tool or a command. It was that real IT environments are always messier, more surprising, and more interesting than any lab. Printers disconnect for no reason. GEO IP filters block legitimate traffic. Clients buy the wrong cable. Servers lose their iDRAC passwords. Plans change the day before a migration.

None of that is in a textbook. And handling it — staying calm, researching, asking the right questions, finding the fix — is what separates someone who knows IT from someone who can *do* IT.

I came in able to do IT in a lab. I'm leaving able to do it in the real world.
