### New Employee Desktop Setup — Windows 11 Clean Install
> Setting up two new desktops for new employees. Flashing a clean Windows 11 copy to remove Dell bloatware.

- Began flashing a clean **Windows 11** installation onto two new Dell desktops
- During installation on the first machine, ran into an issue — the **M.2 SSD was not appearing as an available partition** in the Windows installer
- Confirmed storage was physically present by checking **BIOS** — drive was detected at the hardware level
- Researched the issue and found it is a well-documented problem: the Windows 11 installer lacks the necessary **storage controller drivers** for certain Dell M.2 configurations out of the box
- **Resolution:**
  - Looked up the exact service model through Dell's support site
  - Downloaded the correct **Dell storage controller driver** for the model
  - Extracted the driver files into a folder and placed it on the same USB flash drive as the Windows 11 installer
  - Rebooted and launched the installer — selected "Load Driver" and pointed it to the extracted driver folder
  - The M.2 SSD immediately populated as an available partition
  - Proceeded with the clean Windows 11 installation successfully on both machines

## What I Learned
The M.2 SSD issue is one of those problems that looks confusing at first — the drive shows up in BIOS, so it's not a hardware failure, but the OS installer can't see it. Understanding that the Windows installer has its own driver requirements separate from BIOS detection is a key troubleshooting distinction. Loading drivers mid-install is a skill that comes up regularly in enterprise imaging environments, and knowing to look up the exact Dell service model to find the right driver is the correct approach. Research forums confirmed this is a widespread issue on newer Dell hardware, so recognizing the pattern early and going straight to the driver fix saved significant time.
