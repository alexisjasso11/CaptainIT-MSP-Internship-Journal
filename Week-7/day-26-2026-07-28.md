## What I Learned
Plans change in IT — sometimes hardware decisions get revisited mid-project based on scope, cost, or workload requirements. The OptiPlex 3080 is a practical choice for a single DC VM rather than spinning up a full rack server. The silver lining is that going through this process a second time on different hardware reinforces the Windows Server configuration workflow and makes the steps more automatic. This server is also going to a live on-site migration, which means the stakes are higher than lab work — good motivation to get it right.
